# Discovify Server

A Spring Boot API for authentication, catalog management, playback signals and personalized discovery. MySQL stores application records, Redis caches derived results, and MinIO serves media. A private Python service handles recommendation retrieval and agent requests.

See the [root README](../README.md) for local setup. User-supplied catalog names, lyrics and comments retain their original language.
